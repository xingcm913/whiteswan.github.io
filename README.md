# Alex Rivera · 个人作品集官网

一个现代化、响应式的个人作品集网站，展示全栈开发与 UI 设计作品。

## 特性

- 响应式设计，适配桌面 / 平板 / 手机
- 深色 / 浅色主题切换（自动跟随系统偏好，记忆选择）
- 滚动揭示动画与统计数字滚动
- 玻璃拟态导航 + 移动端汉堡菜单
- 零构建依赖，纯静态 HTML / CSS / JS，开箱即用

## 页面区块

1. **Hero** — 首屏介绍与社交链接
2. **关于** — 个人简介与数据统计
3. **技能** — 前端 / 后端 / DevOps / 设计四大方向
4. **作品** — 精选项目卡片
5. **经历** — 职业时间线
6. **联系** — 邮箱与社交入口

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 部署

已通过 GitHub Pages 部署，访问地址见仓库的 Pages 设置。

## 技术栈

- HTML5 语义化结构
- 原生 CSS（CSS 变量 + Grid + Flexbox）
- 原生 JavaScript（Intersection Observer / localStorage）
- 字体：Inter + JetBrains Mono
